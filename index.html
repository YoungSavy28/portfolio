01

Reads the plan's own legend

A hybrid computer-vision and vision-language-model pipeline converts electrical floor plans into priced takeoffs, reading each plan's own legend through structured JSON output.

02

Finds every symbol

Multi-scale template matching with non-maximum suppression, plus rule-based filters — connected-component text-row detection and OCR checks — remove false positives like letters in room labels.

03

Traces the dashed wires

A dashed-wire tracer built on color segmentation, union-find clustering and minimum-spanning-tree paths links switches to fixtures and measures runs in feet from a user-set scale.

04

Prices with receipts

A search-grounded pricing step extracts part prices with source links and accepts a price only if it appears verbatim in the cited result, then totals materials, labor and contingency.

05

Human in the loop

A review UI with SVG pan/zoom, pinch-to-zoom, retype/remove detections and hand-drawn runs, on a Flask REST API — verified end to end with Playwright tests.
